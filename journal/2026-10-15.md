## 2026-10-15
Done: Installed the Wazuh indexer, server and dashboard. I chose the all-in-one installation because it is enough for a lab.
Problem: The Wazuh indexer did not start (exit code 1). `systemctl` only showed "failed with result 'exit-code'" and no root cause.
Root cause: 
- `journalctl` showed that there was no space left on the disk, and `df -h` confirmed that `/` was 100% full.
- The Ubuntu installer had created `ubuntu-lv` using only half of the volume group: 16.5 GB out of 33 GB. The other half was still free in the VG (`VFree`). I confirmed this with `lsblk -f`, `pvs`, `vgs` and `lvs`.
Fix: `sudo lvextend -r -l +100%FREE ubuntu-vg/ubuntu-lv`. Now `/` has about 33 GB.
Second problem: The indexer still did not start after I extended the disk. `journalctl -u wazuh-indexer` showed `java.nio.file.AccessDeniedException: /etc/wazuh-indexer/backup`. After reading the documentation, I changed the ownership with `sudo chown -R wazuh-indexer:wazuh-indexer /etc/wazuh-indexer`.
